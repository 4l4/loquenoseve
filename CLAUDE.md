# Lo que no se ve — визуальная новелла (Twine / Tweego + SugarCube 2)

Игра на испанском (риоплатский вариант: *vos*, *mirá*, *sentate*). Тексты персонажей не переводить и не «исправлять» на нейтральный испанский.

## Команды

```bash
npm install          # один раз
npm run setup        # скачать Tweego 2.1.1 + SugarCube 2.37.3 в .tools/ (один раз)
npm run check        # статическая проверка: битые ссылки, несуществующие картинки/персонажи
npm run build        # картинки → dist/img/*.webp, затем src/ → dist/index.html
npm run dev          # то же + Tweego watch + сервер http://localhost:8080 (PORT=… чтобы сменить)
npm run deploy       # build + публикация dist/ в ветку gh-pages → https://4l4.github.io/loquenoseve/
```

После любой правки сценария: `npm run check && npm run build`. Обе команды должны пройти без ошибок.
Готовая игра — папка `dist/` целиком (`index.html` + `img/`). Хостинг: GitHub Pages из ветки `gh-pages` (её пишет только `npm run deploy`, руками не трогать); исходники — в `main`.

## Структура

```
src/story/StoryData.tw   метаданные: IFID, формат, стартовый пасаж (не менять IFID)
src/story/StoryInit.tw   глобальные переменные ($regla, $fecha, $cabala, $puntos, $apariencia) и setup.links
src/story/characters.js  реестр персонажей: id → имя, спрайт, цвет имени
src/ui/vn.js             движок VN-слоя (макросы ниже)
src/ui/vn.css            оформление
src/scenes/NN-*.tw       сцены, по файлу на главу/локацию, номера по порядку сюжета
resources/               исходные PNG (только читать)
docs/plot.md             сценарий, извлечённый из plot.svg (Miro)
docs/assets.md           каталог картинок: что изображено и к какой сцене относится
```

Tweego собирает все `.tw`, `.js`, `.css` из `src/` рекурсивно — новые файлы подключать не нужно.

## Как писать сцены

Пасаж = одна непрерывная сцена (одна локация/момент). Каждый `[CLIC]` из сценария — новый `<<beat>>`.

```
:: Taxi
<<bg "background_03">>                        ← обязательно первой строкой: задаёт фон (нужно для загрузки сохранений)
<<beat>><<say "taxista">>— ¿Primera vez en Buenos Aires?<</say>><</beat>>
<<beat>><<say "yo">>— Sí. Primera vez.<</say>><</beat>>
<<beat>><<bg "background_05-face01">>Miro mi reflejo en el vidrio…<</beat>>
<<beat>><<choices>>
	[[Mirar por la ventana|Autopista]]
	[[Elegir mi apariencia|Apariencia]]
<</choices>><</beat>>
```

### Макросы (src/ui/vn.js)

| Макрос | Что делает |
|---|---|
| `<<bg "ассет" ["fade"\|"slow"\|"cut"]>>` | сменить фон (кроссфейд 0.6 с / 1.5 с / мгновенно) |
| `<<char "id" ["left"\|"center"\|"right"\|"NN%"\|"hide"]>>` | показать/переместить/убрать спрайт; id из `setup.chars` или имя ассета; `"72%"` — центр спрайта на 72% ширины экрана |
| `<<nochar>>` | убрать всех персонажей (при смене пасажа они убираются автоматически) |
| `<<fx "ассет" [мс]>>` | вспышка-оверлей (`lighting_01/02`), по умолчанию 1200 мс |
| `<<say "id">>текст<</say>>` | реплика с именем; id из `setup.chars`, иначе строка выводится как имя |
| `<<beat>>…<</beat>>` | один «клик»: показывается по очереди, клик/пробел/Enter/→ — следующий |
| `<<nextscene "Пасаж">>` | куда перейти по клику после последнего beat (если нет ссылок) |
| `<<choices>>[[…]] [[…]]<</choices>>` | блок кнопок выбора |
| `<<puntos N>>` | +N «puntos porteños» (виден счётчик справа сверху) |

Правила:
- Текст вне `<<beat>>` рендерится сразу. Туда ставьте только `<<bg>>`, `<<char>>`, `<<fx>>`, `<<nextscene>>`.
- `<<beat>>` нельзя вкладывать друг в друга и в `<<if>>` внутри другого beat. Условный beat: `<<if $x>><<beat>>…<</beat>><</if>>` на верхнем уровне пасажа.
- Пока в beat есть ссылки/кнопки, клик по фону не листает: игрок обязан выбрать.
- Переносы строк в коде не выводятся (`Config.passages.nobr`). Для абзаца внутри beat используйте `<br>` или `<p>`.
- Ремарки сценария (`FONDO:`, `SONIDO:`) не выводятся текстом, а превращаются в `<<bg>>` / аудио.
- Выбор, который запоминается на всю игру, делается ссылкой с сеттером: `[[…el primer bocado es para el mayor…|Fecha][$regla to "mayor"]]`.
- Значения переменных фиксированы в комментариях `StoryInit.tw`. Новую переменную сначала объявить там.
- Пасажи-экраны (меню, финал главы, длинный текст) помечаются тегом `[menu]`: панель по центру вместо диалогового окна.
- Пустой `<<beat>><</beat>>` прячет панель и показывает просто картинку (кинематографичная пауза до клика).
- Звуковые ремарки, пока нет аудио, пишутся как `<span class="vn-sfx">*la campanita de la puerta*</span>`.
- Персонаж появляется на экране в момент своей первой реплики (`<<char>>` в том же beat, что и `<<say>>`), а не заранее.
- Героиня (`yo`, спрайт `character_17-face01`) появляется, когда говорит, а её нет на фоне (с кафе главы 1 и дальше; реплика в такси — без спрайта).
- Перуанка (`cocinera`) стоит на `"72%"`, Матео — `left` (когда в кадре оба) или `right`.
- Новый говорящий персонаж добавляется в `src/story/characters.js` (иначе `npm run check` ругается).
- Имена пасажей уникальны по всему проекту. Пишите их по-испански, коротко и без кавычек.

### Звук

Аудиофайлов пока нет. Когда появятся: положить в `dist/audio/` (или добавить копирование в `scripts/images.mjs`) и использовать штатные `<<cacheaudio>>` (в StoryInit) / `<<audio "id" play>>` SugarCube.

## Источники сюжета

- `docs/plot.md` — текст доски Miro. Порядок строк местами перемешан между колонками, поэтому сверяйтесь по смыслу и по `docs/assets.md`.
- Доска Miro: https://miro.com/app/board/uXjVEX7-HPk=/ (MCP Miro). Если доступ есть, это первоисточник.
- Внешние части проекта (MAPA, RECETAS, PELÍCULA) — URL в `setup.links` в `StoryInit.tw`, пока стоят заглушки `#`.
